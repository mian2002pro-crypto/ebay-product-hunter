# Miaan eBay Hunter & Sourcer

Chrome Extension (Manifest V3).

## Current workflow
1. Open an eBay listing.
2. Click Miaan Hunter.
3. Capture the real title, displayed price text, seller, image URL and listing URL.
4. Save it locally with Chrome extension storage.
5. Open a direct AliExpress search for the same product title.

No eBay or AliExpress API key is required for this browser workflow.

This is the foundation for the full Hunter + Sourcer extension. The extension must never fabricate sales counts, supplier prices, or trend data.
